# AI Medical Expert System

## Project Description

This project is a Rule-Based Expert System developed using Python and Flask. It diagnoses possible diseases based on user-selected symptoms by applying Forward Chaining.

---

## Features

- Rule-Based AI
- Forward Chaining
- Multi-Step Inference
- Medical Diagnosis
- Inference Log
- Dashboard
- Responsive UI

---

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript

---

## How to Run

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
